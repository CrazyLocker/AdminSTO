## 🎉 Что вошло в 1.2.0

### Функциональность

- переработан календарь «Запись»: режимы «Неделя/Месяц», карточки записей,
  цветная полоса статуса заказа, легенда, счётчики в заголовках дней;
- 7 тем AtlantaFX и вкладка «Внешний вид»; выбор сохраняется в
  `config/theme.txt` и применяется при следующем запуске;
- «зебра» таблиц и голубая подсветка выбора, в том числе в диалогах;
- восстановленное окно ограничивается границами экрана;
- 8 вкладок настроек, включая лояльность и импорт/экспорт;
- двухтрековая лояльность: звёзды ТО и Stage тюнинга со скидками 5/10/15 %.

### Исправленные дефекты

- зависание при двойном клике по клиенту (диалоги завершают
  `CompletableFuture` при закрытии);
- поиск клиента по телефону в человеческом формате;
- импорт остатка `12.0` больше не обнуляется;
- удаление из кэша `DataStore` по `id`, а не по ссылке;
- `ToPart.save()` не теряет правки;
- повторное добавление пары в legacy-связях обновляет запись; кнопки
  «Очистить дубликаты» удалены.

### Инфраструктура

- `jpackage` собирает app-image `build/jpackage/AdminSTO`;
- `.github/workflows/release.yml` по тегу `v*` публикует
  `AdminSTO-Windows.zip` и GitHub Release;
- `tools/seed_test_data.py` и `tools/seed_appointments.py` + описание в
  `docs/SEED_TEST_DATA.md`;
- CI: `build`, `ui-test` (Xvfb), `mutation` (workflow_dispatch).

## ⚠️ Остаточные риски

| Риск | Влияние | Что делать |
|---|---|---|
| Нет аутентификации и ролей | Любой пользователь ОС имеет полный доступ | Для коммерческого контура — отдельная задача |
| `views`/`dialogs` не входят в JaCoCo | Общий процент 34,5 % выглядит низким | Оценивать UI отдельно по `uiTest` |
| Крупные `SettingsView`, `AbstractDatabase`, `DashboardView`, `AppointmentView` | Сложность сопровождения | Постепенный рефакторинг, см. `CODE_REVIEW.md` |
| Дубли в `service_parts` при повторном добавлении пары | Лишние строки в дереве связей | Уникальный индекс/upsert |
| `ScheduleService` не отменяет `ScheduledFuture` | Выключение автобэкапа не останавливает задачу до перезапуска | Хранить `ScheduledFuture` и отменять |
| Портативная сборка только Windows | Нет Linux/macOS-пакета | Отдельная задача упаковки |
| Метрики сняты на Linux/headless | Windows-цифры могут отличаться на доли процента | Указано в TEST_REPORT |

## 🎯 Рекомендация

Версия **1.2.0 готова к релизу**. Перед публикацией:

1. прогнать `./gradlew build` и `./gradlew uiTest` на релизной ревизии;
2. собрать `./gradlew jpackage` на Windows и запустить `AdminSTO.exe` на
   демо-данных;
3. создать тег `v1.2.0` — workflow соберёт ZIP и GitHub Release;
4. приложить к релизу `AdminSTO-Windows.zip`.
