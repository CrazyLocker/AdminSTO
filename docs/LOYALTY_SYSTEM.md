# Система лояльности AdminSTO

## Общая концепция
Внедряется двухтрековая система лояльности. Скидки не суммируются в лоб, а разделены по категориям товаров/услуг.

## 1. Шкала ТО (Регулярность)
- **Триггер:** Закрытие заказа, в котором есть услуга с типом «ТО» (Техническое обслуживание).
- **Условие начисления:** Разница пробега между текущим и предыдущим ТО должна быть в заданном диапазоне (от 5 000 до 10 000 км).
- **Начисление:** 1 звезда (максимум 5).
- **Эффект скидки:** Постоянная скидка на работы (услуги) и расходники (масло, фильтры).
  - 3 звезды = 5%
  - 4 звезды = 10%
  - 5 звезд = 15%
- **Потеря прогресса:** Если клиент пропустил интервал (приехал позже 10 000 км), новая звезда не начисляется, но старые не сгорают.

## 2. Шкала Тюнинга (Статус)
- **Триггер:** Общая сумма, потраченная клиентом на запчасти/услуги категории «Тюнинг».
- **Начисление:** Присвоение статуса на основе накопительной суммы.
  - Stage 1 (5%): от 30 000 до 100 000 руб.
  - Stage 2 (10%): от 100 001 до 300 000 руб.
  - Stage 3 (15%): больше 300 000 руб.
- **Эффект скидки:** Постоянная скидка на запчасти и работы категории «Тюнинг».
- **Потеря прогресса:** Не сгорает (накопительная система).

## 3. Логика применения в интерфейсе (CreateOrderDialog)
- При добавлении услуги/запчасти в заказ система проверяет её категорию.
- Если категория «ТО/Расходники» — применяется скидка по Шкале ТО.
- Если категория «Тюнинг» — применяется скидка по Шкале Тюнинга.
- Если в заказе есть и то, и другое — скидка применяется отдельно к каждой строке, в зависимости от её категории.

## 4. Визуализация в карточке клиента
Вывод двух плашек:
- Статус ТО: [★★★★☆] — Скидка 10% на работы.
- Статус Тюнинга: [Stage 2] — Скидка 10% на тюнинг.

## 5. Настройки этапа 1

Все числовые параметры системы читаются из `SettingService` (таблица
`app_settings`). Если настройка отсутствует, используется значение по
умолчанию из этого документа. Ключи и значения по умолчанию объявлены
константами `LoyaltyService`.

| Ключ | По умолчанию | Назначение |
|---|---|---|
| `loyalty.maintenance.min_mileage` | `5000` | Минимальная разница пробега между ТО, км |
| `loyalty.maintenance.max_mileage` | `10000` | Максимальная разница пробега между ТО, км |
| `loyalty.maintenance.max_stars` | `5` | Максимум звёзд ТО |
| `loyalty.maintenance.stars3.discount` | `5` | Скидка на ТО при 3 звёздах, % |
| `loyalty.maintenance.stars4.discount` | `10` | Скидка на ТО при 4 звёздах, % |
| `loyalty.maintenance.stars5.discount` | `15` | Скидка на ТО при 5 звёздах, % |
| `loyalty.tuning.stage1.min_amount` | `30000` | Начало Stage 1, руб. |
| `loyalty.tuning.stage1.discount` | `5` | Скидка Stage 1, % |
| `loyalty.tuning.stage2.min_amount` | `100000` | Порог Stage 2 (скидка действует при сумме больше порога), руб. |
| `loyalty.tuning.stage2.discount` | `10` | Скидка Stage 2, % |
| `loyalty.tuning.stage3.min_amount` | `300000` | Порог Stage 3 (скидка действует при сумме больше порога), руб. |
| `loyalty.tuning.stage3.discount` | `15` | Скидка Stage 3, % |

Накопленные показатели хранятся в `clients.maintenance_stars` и
`clients.tuning_total`, категории — в `services.category` и
`spare_parts.category` (значения `REGULAR`, `MAINTENANCE`, `TUNING`).
Экран редактирования этих настроек появится позже; логика уже читает их
по ключам и не требует изменений при добавлении UI.
